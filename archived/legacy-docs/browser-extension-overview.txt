----------------------------------------------------------------------------------------------------
BOTTOM LINE
----------------------------------------------------------------------------------------------------
Sarvam nets the largest saving at every volume level (server downsize minus its own tiny API
cost). Gemini also stays net-positive but with a much thinner margin at high volume. OpenAI is the
only option where high-volume API cost can exceed the hosting saving it unlocks — its Net column
goes negative. At this extension’s actual current low-volume traffic, none of this is urgent:
staying local costs ₹0 and the only real cost is ~12.6s vs. ~4.6s wait per note (measured). If
reps start complaining about the wait, Sarvam is the option to test first — not Gemini or OpenAI.
